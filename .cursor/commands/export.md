# /export — 챗 세션 요약 및 프롬프트 추출

현재 챗창의 전체 대화를 분석하여 **report**와 **prompting** 두 파일을 생성·저장한다.

## 1. 다음 prefix 번호 결정

프로젝트 루트 기준 `report/`, `prompting/` 폴더를 확인하고, 파일명이 `{숫자}_` 패턴으로 시작하는 파일들의 **최대 숫자 + 1**을 다음 prefix로 사용한다.

- 두 폴더 중 **더 큰 prefix**를 기준으로 한다 (동기화 유지).
- 해당 패턴 파일이 없으면 prefix는 `0`이다.
- 예: `0_`, `1_`, `2_` … 순차 증가.

```text
예시 파일명
  report/0_export_report_2026-06-11_1430.md
  prompting/0_export_prompting_2026-06-11_1430.md
```

## 2. report 파일 작성

`report/{prefix}_export_report_{YYYY-MM-DD_HHmm}.md` 경로에 저장한다.

포함 항목:

1. **세션 개요** — 주제, 참여 역할(PM/개발자 등), 대화 목적
2. **작업 요약** — 수행한 분석·결정·산출물
3. **핵심 발견 / 문제점** — Mom Test, 기술 이슈, 리스크
4. **결정 사항** — 확정된 내용과 미결정 항목
5. **다음 액션** — 후속 작업 제안 (있을 경우)
6. **메타정보** — export 시각, prefix 번호

## 3. prompting 파일 작성

`prompting/{prefix}_export_prompting_{YYYY-MM-DD_HHmm}.md` 경로에 저장한다.

포함 항목:

1. **프롬프트 목록** — 사용자(user)가 보낸 메시지를 **시간순**으로 정리
2. 각 항목 형식:

```markdown
### [순번] 사용자 프롬프트

> (원문 그대로 인용)

**맥락/의도:** (한 줄 요약)
```

3. **재사용 가능한 프롬프트 패턴** — 반복되거나 효과적이었던 질문/지시가 있으면 별도 섹션에 정리

## 4. 실행 규칙

- `report/`, `prompting/` 폴더가 없으면 생성한다.
- 파일은 **UTF-8** 마크다운으로 저장한다.
- 저장 후 사용자에게 다음을 알린다:
  - 사용된 prefix 번호
  - 생성된 두 파일의 전체 경로
  - 각 파일 3~5줄 요약

## 5. 주의사항

- 현재 챗창 대화만 대상으로 한다. 다른 챗 세션 내용은 포함하지 않는다.
- report는 **사실 기반**으로 작성하고, 추측은 "추정"으로 표시한다.
- prompting은 사용자 메시지 **원문을 최대한 보존**한다 (요약으로 대체하지 않는다).
- 이미 동일 prefix 파일이 존재하면 번호를 다시 계산하여 충돌을 피한다.
