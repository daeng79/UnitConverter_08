- **이번 세션 범위:** Rule, Command, (Skill), Test Loop만 — Contract·Component·구현은 후속
- **주제:** 코드 전 범위·검증 기준 고정 (솔루션 최소화)
- **금지 항목:** OCP 전면 리팩토링, 설정 외부화, 동적 등록, JSON/CSV 출력, “데모 OK” 범위 단정

### 미결정 (PM 확인 필요 — 워크북 Input으로 명시)

3. 음수 입력 처리 (에러 vs 허용)
4. 동적 등록 UX (런타임 vs 파일 저장) — 후속 세션
