### 문서·범위

- README 원본 요구(OCP·동적 등록·JSON/CSV)와 M1 in/out을 PRD·README에서 **명시적 분리** 완료

- ARRR 파이프라인: `red-test-plan` → `red-skeleton` → `tdd-red` → `green-minimal` → `golden-master` → `refactor-smell` → (예정) `refactor-safe`

### 기술 Gap (변경 없음)

- `src/unit_converter.py` stub · RED R1 1건만 (`test_convert_all_meter_to_feet_and_yard`)
- `doc/PRD.md`·`.cursorrules` 일부 메타에 `UnitConverter_08` 표기 잔존 (추정: 복사 잔재)
